## 🚀 What is QRForge?

QRForge is a powerful QR code toolkit that allows you to create, scan, customize, save, and manage QR codes directly on your Android device.

It is designed to be simple, fast, and easy to use while providing useful QR tools in one place.

🔒 Privacy-focused  
📴 Core features work offline  
⚡ Fast and lightweight  
📱 Built as a native Android app  
🚫 No account required for core features

# ✨ Features

## 🧾 QR Code Generator

Create QR codes for many different types of information.

Supported QR types include:

- 📝 Text QR
- 🌐 URL / Website QR
- 📶 Wi-Fi QR
- 📞 Phone Number QR
- ✉️ Email QR
- 💬 SMS QR
- 👤 Contact QR
- 📍 Location QR

Simply select the type, enter the information, and QRForge generates the QR code instantly.

---

## 🎨 QR Code Customization

QRForge allows you to customize the appearance of generated QR codes.

Customization options include:

- 🎨 Foreground color
- 🖌️ Background color
- 🌈 Gradient colors
- 🔲 QR dot styles
- 👁️ Corner eye styles
- ✨ Custom QR appearance

This allows you to create QR codes that look more unique than standard black-and-white QR codes.

---

## 📷 Camera QR Scanner

Scan QR codes directly using your Android phone camera.

Features include:

- 📷 Live camera scanning
- 🎯 Automatic QR detection
- 🔄 Camera switching
- ▶️ Start camera
- ⏹️ Stop camera
- 📄 Scan result display

QRForge automatically detects supported QR codes while they are visible inside the scanner frame.

---

## 🖼️ Scan QR Codes From Images

Already have a QR code saved as an image?

QRForge can scan QR codes directly from images stored on your device.

Useful for:

- 📸 Screenshots
- 📥 Downloaded QR codes
- 🖼️ Saved images
- 💬 QR codes received from other people

You do not need another phone to scan a QR code from an image.

- 🧹 Clear history
- ⚡ Quickly reuse previous QR data

Favorites are useful for QR codes that you use regularly and do not want to search for again.

# 📱 Installation

QRForge is currently distributed as an Android APK through GitHub Releases.

## 📥 How to Install

1. Open the QRForge release page:

   https://github.com/DibyaBuilds/QRForge/releases/tag/v1.0.0

2. Download:

   `QRForge-v1.0.0.apk`

3. Open the downloaded APK on your Android device.

4. Android may ask you to allow installation from your browser or file manager.

5. Allow the permission if you trust the source.

6. Tap **Install**.

7. Open **QRForge**.

---

## 🔐 Android Security Notice

Because QRForge is currently distributed directly through GitHub instead of the Google Play Store, Android may display a warning such as:

- ⚠️ Install unknown apps
- ⚠️ Unknown source
- ⚠️ This file may be harmful

This is a normal Android warning for APK files downloaded outside the Play Store.

Always download QRForge only from the official GitHub repository or official website.

# 🛠️ Technology

QRForge is built as a native Android application.

Main technologies used include:

- 🟣 Kotlin
- 🤖 Android SDK
- 🎨 Jetpack Compose
- 📷 CameraX
- 🧠 Google ML Kit Barcode Scanning
- 🔳 ZXing
- ⚙️ Kotlin Coroutines
- 💾 Android Storage APIs
- 🏗️ Gradle

---

# 🔒 Privacy

QRForge is designed primarily as a local QR utility.

The app's core QR generation, scanning, customization, history, and favorites features operate directly on the Android device.

🔒 No account is required for core features.

📴 Core QR features can work offline.

📱 Data is handled locally for normal QR operations.

# 🔑 Permissions

QRForge may request Android permissions depending on the feature being used.

## 🖼️ Media / File Access
