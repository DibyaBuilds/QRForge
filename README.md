# QRForge – Offline QR Generator & Scanner

Create, customize, scan & print QR codes — **100% offline**, right in your browser.

🔗 **Live app:** https://dibyabuilds.github.io/QRForge/

## ✨ Features
- 8 QR types: Text, URL, Wi-Fi, Phone, Email, SMS, Contact, Location
- Custom colors, gradients, dot styles, corner eyes & logo in center
- Export as PNG / PDF, copy image & data
- Scan QR codes via webcam or image upload
- Batch generation + printable QR sheets
- History & favorites (stored only on your device)
- Dark/Light mode, installable as an app (PWA), works offline

## 🔒 Privacy
Everything is processed locally in your browser.
No servers. No APIs. No tracking. No uploads. Ever.

## 🚀 Use it
Open the link — nothing to install.
On phones: browser menu → **Install app / Add to Home Screen**.

## 🛠️ Tech
Pure HTML + CSS + Vanilla JavaScript with local libraries (qrcodejs + jsQR).
